# 极简 Coding Agent 开发计划书（一阶段）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个具备「读写文件 + 执行 shell 命令」能力、可完成"文件总结 / 按需求写脚本"等基础任务的极简 coding agent，提供 Web 界面，并上传 GitHub 交付仓库地址。

**Architecture:** Python + FastAPI 提供 Web 后端与静态页面托管；前端为零构建的纯 HTML/CSS/JS 单页聊天界面；核心是一个手写 agent 循环（基于 OpenAI 兼容接口的 function calling），循环调用 LLM 与三个工具（`read_file` / `write_file` / `run_command`）直至产出最终回答。

**Tech Stack:** Python 3.10+、FastAPI、uvicorn、openai（OpenAI Python SDK，兼容 DeepSeek/Qwen/GLM/Ollama 等）、python-dotenv、pytest、httpx（API 测试）。

**Spec:** 本阶段无独立 spec 文件，需求由任务书直接给定，详见下文「需求分析」章节。计划据该需求编写。

## 全局约束（Global Constraints）

- Python >= 3.10
- 依赖仅列于 `requirements.txt`：`fastapi`、`uvicorn[standard]`、`openai>=1.0`、`python-dotenv`、`pytest`、`httpx`
- LLM 通过 **OpenAI 兼容接口**接入，`base_url` / `api_key` / `model` 全部通过环境变量配置，**禁止硬编码密钥**
- 密钥通过 `.env` 注入，仓库仅提交 `.env.example`（`.gitignore` 排除 `.env`）
- 前端零构建：纯 HTML/CSS/JS，由 FastAPI 静态托管，不引入 Node 构建链
- 所有 Python 逻辑（工具、agent 循环、API）必须有对应 pytest 测试
- Agent 循环调用 LLM 时需有最大迭代上限（默认 10），防止死循环
- `run_command` 必须设置超时（默认 30s）；本阶段接受 `shell=True` 的安全风险并在 README 标注，硬化为后续阶段任务

# 需求分析

## 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| FR1 | 文件读取 | agent 可读取指定路径文件内容（文本） |
| FR2 | 文件写入 | agent 可将内容写入指定路径（覆盖写） |
| FR3 | shell 执行 | agent 可执行 shell 命令并取回 stdout/stderr |
| FR4 | 基础任务 | 支持"总结指定文件""按需求编写脚本"等任务 |
| FR5 | Web 交互 | 浏览器打开页面 → 输入需求 → 展示 agent 最终回答与工具调用过程 |
| FR6 | 可配置接入 | 通过环境变量切换 OpenAI / 兼容服务（DeepSeek、Qwen、GLM、Ollama 等） |

## 非功能需求

- **极简**：代码量控制在最小，核心 agent 循环 ≤ 100 行
- **可测试**：agent 循环不依赖真实 API，通过注入 client 可单测
- **可交付**：含 README、`.env.example`、`.gitignore`，可直接 clone 运行

## 验收标准

1. 用户输入"总结 `docs/README.md` 的内容"，agent 调用 `read_file` 后返回正确摘要
2. 用户输入"写一个打印 hello 的 Python 脚本并运行它"，agent 调用 `write_file` + `run_command` 并返回运行结果
3. 三条核心命令 `pip install -r requirements.txt` → 配置 `.env` → `uvicorn app.main:app` 能启动并完成上述 1/2
4. `pytest` 全绿

import subprocess


def read_file(path: str) -> str:
    with open(path, "r", encoding="utf-8", errors="replace") as f:
        return f.read()


def write_file(path: str, content: str) -> str:
    with open(path, "w", encoding="utf-8") as f:
        f.write(content)
    return f"已写入文件: {path}"


def run_command(command: str, timeout: int = 30) -> str:
    try:
        result = subprocess.run(
            command,
            shell=True,
            capture_output=True,
            text=True,
            timeout=timeout,
        )
        return (result.stdout + result.stderr).strip() or "(无输出)"
    except subprocess.TimeoutExpired:
        return f"命令超时（>{timeout}s）: {command}"


TOOLS = [
    {
        "type": "function",
        "function": {
            "name": "read_file",
            "description": "读取指定路径文件的文本内容",
            "parameters": {
                "type": "object",
                "properties": {
                    "path": {"type": "string", "description": "文件路径"}
                },
                "required": ["path"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "write_file",
            "description": "将内容写入指定路径文件（覆盖写）",
            "parameters": {
                "type": "object",
                "properties": {
                    "path": {"type": "string", "description": "文件路径"},
                    "content": {"type": "string", "description": "要写入的内容"},
                },
                "required": ["path", "content"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "run_command",
            "description": "执行 shell 命令并返回 stdout/stderr",
            "parameters": {
                "type": "object",
                "properties": {
                    "command": {"type": "string", "description": "要执行的 shell 命令"}
                },
                "required": ["command"],
            },
        },
    },
]

HANDLERS = {
    "read_file": read_file,
    "write_file": write_file,
    "run_command": run_command,
}

import json


def run_agent(client, model, messages, tools, handlers, max_iterations=10):
    """执行 agent 循环：反复调用 LLM，需要时执行工具，直到产出最终回答。

    返回 (最终回答文本, 工具调用 trace 列表)。
    """
    trace = []
    for _ in range(max_iterations):
        resp = client.chat.completions.create(
            model=model,
            messages=messages,
            tools=tools,
            tool_choice="auto",
        )
        msg = resp.choices[0].message

        if not msg.tool_calls:
            return (msg.content or "", trace)

        messages.append(
            {
                "role": "assistant",
                "content": msg.content,
                "tool_calls": [
                    {
                        "id": tc.id,
                        "type": "function",
                        "function": {
                            "name": tc.function.name,
                            "arguments": tc.function.arguments,
                        },
                    }
                    for tc in msg.tool_calls
                ],
            }
        )

        for tc in msg.tool_calls:
            name = tc.function.name
            args = json.loads(tc.function.arguments or "{}")
            result = handlers[name](**args)
            trace.append({"tool": name, "args": args, "result": str(result)})
            messages.append(
                {"role": "tool", "tool_call_id": tc.id, "content": str(result)}
            )

    return ("已达到最大迭代次数，任务可能未完成。", trace)
```

from pathlib import Path

from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles
from openai import OpenAI
from pydantic import BaseModel

from .agent import run_agent
from .config import load_config
from .tools import TOOLS, HANDLERS

config = load_config()

app = FastAPI(title="Minimal Coding Agent")

app.mount(
    "/static",
    StaticFiles(directory=Path(__file__).parent / "static"),
    name="static",
)


class ChatRequest(BaseModel):
    message: str


class ChatResponse(BaseModel):
    answer: str
    trace: list


@app.get("/")
def index():
    from fastapi.responses import FileResponse

    return FileResponse(Path(__file__).parent / "static" / "index.html")


@app.post("/api/chat", response_model=ChatResponse)
def chat(req: ChatRequest):
    client = OpenAI(api_key=config.api_key, base_url=config.base_url)
    messages = [{"role": "user", "content": req.message}]
    answer, trace = run_agent(client, config.model, messages, TOOLS, HANDLERS)
    return ChatResponse(answer=answer, trace=trace)
```

// app.js
const chat = document.getElementById("chat");
const form = document.getElementById("form");
const input = document.getElementById("message");

function addBubble(text, cls) {
  const div = document.createElement("div");
  div.className = "bubble " + cls;
  div.textContent = text;
  chat.appendChild(div);
  chat.scrollTop = chat.scrollHeight;
}

form.addEventListener("submit", async (e) => {
  e.preventDefault();
  const message = input.value.trim();
  if (!message) return;
  addBubble(message, "user");
  input.value = "";
  try {
    const res = await fetch("/api/chat", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ message }),
    });
    const data = await res.json();
    if (data.trace && data.trace.length) {
      data.trace.forEach((t) =>
        addBubble(`🛠 ${t.tool}(${JSON.stringify(t.args)})\n→ ${t.result}`, "trace")
      );
    }
    addBubble(data.answer, "assistant");
  } catch (err) {
    addBubble("请求失败: " + err.message, "assistant");
  }
});
